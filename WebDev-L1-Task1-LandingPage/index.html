Built for how freelancers actually work.

Not a scaled-down version of enterprise software. Waypoint is built around the way one person runs a business — a handful of active clients, work that doesn't fit neat categories, and no time for tools that need a manual.

  • Time tracking that doesn't feel like a timesheet

    Start a timer from your terminal, browser, or phone. It stays attached to the right project automatically.

  • A client portal, without the setup

    Every client gets a private link showing project status and invoices — no login, no onboarding call.

  • Invoice reminders that aren't from you

    Waypoint follows up on overdue invoices automatically, so you never have to send an awkward nudge.

  • One dashboard, every active project

    See what's owed, what's overdue, and what's due this week — across every client, on one screen.
